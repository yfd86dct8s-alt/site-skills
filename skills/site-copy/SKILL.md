# Site copy

Our own skill. Nothing here installs, runs scripts, or fetches remote instructions. Sources and
licenses: `NOTICE.md`.

## Precedence (highest first)

1. `CLAUDE.md` and Arthur's memories: copy from the visitor's side, no weak numbers, claims need proof,
   no fake/demo data, deliverables in English.
2. The client's dossier: `DECISOES.md`, `02-legal-advertising.md` (regulated clients), approved proof
   ledger, brand voice in `DESIGN.md`.
3. This skill.

Third-party advice that conflicts (e.g. "add a user count", "join 10,000+ teams", SaaS trial/pricing
vocabulary) loses silently. The reference files already apply the overrides.

## When to read what

- Any headline, subhead, CTA, section copy, meta text: `reference/copy-rules.md`.
- Any form, quote funnel, contact block, thank-you/error state, or a page-level conversion review:
  `reference/forms-cro.md`.
- Any number, testimonial, award, "years", "#1", result, guarantee, or any client in a regulated
  industry (law, health, finance): `reference/regulated-claims.md` FIRST.

## Workflow

1. Read the dossier before asking Arthur anything: research, reviews, call notes, competitor copy.
   Use the visitor's own words from reviews and calls.
2. Name the one action this page exists for. One primary CTA label per intent across the whole site.
3. Draft from facts. Where a fact is missing write `[NEED: <what>]` (e.g. `[NEED: differentiator]`,
   `[NEED: proof for "24/7"]`); never invent it to fill the gap.
4. Run the proof ledger (regulated-claims.md): every number/promise/exclusivity gets a source row or is cut.
5. Run the self-check in copy-rules.md (AI tells, swap test, visitor-side test) and the page-level checks
   in forms-cro.md. Fix from facts; swapping synonyms only creates new tells.

## Output

Copy by section with headline, subhead, CTA, plus 2-3 headline/CTA alternatives with one-line rationale
when taste is involved (Arthur decides taste; you decide structure). List every `[NEED: ...]` and every
claim awaiting proof at the end of the message, not buried mid-text.
